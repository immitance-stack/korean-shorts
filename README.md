# 한국어 학습 쇼츠 (korean-shorts)

남녀의 짧은 대화 대본을 보내면, 앞뒤 상황을 덧붙여 **3~4편의 한국어 학습 쇼츠**를 만들고
승인을 받은 뒤 업로드하는 시스템입니다.

## 선생님이 하실 일
1. **월요일이나 화요일**: 새 대화를 열고 대본을 붙여넣기 → 3~4편 줄거리를 보고 "대본 승인"
2. **다음 날부터 매일**: 휴대폰 알림이 오면 영상 2개(영어판, 베트남어판)를 보고
   - 괜찮으면 **"승인"** → YouTube에 자동 업로드
   - 고칠 곳이 있으면 **"수정: (고칠 내용)"**
3. 승인 후 받은 **베트남어 영상 파일**을 TikTok 앱에서 직접 올리기

## 영상 구성
오늘의 주제 → ① 대화 듣기 → 천천히 한 번 더(따라 말하기) · 한국어 + 영어/베트남어 자막

## 구성 요소 (무료)
- 음성: Google Gemini TTS
- 그림·영상: 직접 그린 일러스트 + HyperFrames(오픈소스)
- 번역: DeepL
- 업로드: Zapier(YouTube)

자세한 작업 절차는 `CLAUDE.md`에 있습니다.
